# My Stamp Plugin - تغییرات اعمال شده

## خلاصه تغییرات

این افزونه وردپرس برای شخصی‌سازی مهر، کارت دیجیتال و تجربیات AR طراحی شده است. تغییرات زیر اعمال شده:

## 1. نمایش قیمت اپشن‌ها در مهر AR ✅

- **قبل**: فقط قیمت پایه محصول نمایش داده می‌شد
- **بعد**: قیمت تمام اپشن‌ها (رنگ، شکل، اندازه) به صورت زنده نمایش داده می‌شود
- **مکان**: بخش "Devis en direct" در صفحه کاستومایزر مهر

## 2. تغییر دکمه‌ها ✅

- **دکمه Save**: حذف شد
- **دکمه AR**: به "Next - AR" تغییر یافت
- **آدرس**: همان آدرس AR قبلی حفظ شد

## 3. خودکار کردن لوگو در فرم AR ✅

- **قبل**: کاربر باید لوگو را دوباره آپلود می‌کرد
- **بعد**: لوگو مهر به صورت خودکار در فرم AR قرار می‌گیرد
- **مکان**: اولین target در فرم AR

## 4. بهبود فرآیند کارت دیجیتال ✅

### گزینه کارت فیزیکی
- چک‌باکس "Je veux aussi une carte physique personnalisée" اضافه شد
- اگر انتخاب شود، کاربر به کاستومایزر کارت فیزیکی هدایت می‌شود

### نمایش قیمت
- بخش قیمت‌گذاری اضافه شد
- قیمت پایه کارت دیجیتال
- قیمت اپشن‌ها
- قیمت کل

## 5. پیش‌نمایش زیبا ✅

### کارت دیجیتال
- 3 تم مختلف: Drapeau France، Luxe Navy/Or، Bleu Minimal
- پیش‌نمایش زنده با تغییرات فرم
- امکان تغییر تم

### مهر
- پیش‌نمایش زنده با تغییرات
- امکان جابجایی و تغییر اندازه لوگو و QR
- نمایش شکل‌های مختلف (دایره، بیضی، مربع، مستطیل)

## 6. بهبود داشبورد ✅

### آمار کلی
- تعداد کارت‌های ایجاد شده
- تعداد کل بازدیدها
- تعداد کل کلیک‌ها
- تعداد مهرهای ذخیره شده

### فعالیت اخیر
- نمایش 10 فعالیت آخر کاربر
- نوع فعالیت، IP، تاریخ و ساعت
- اطلاعات کامل برای تحلیل

## ساختار فایل‌ها

### فایل اصلی
- `my-stamp-plugin.php` - فایل اصلی افزونه

### فایل‌های اضافی
- `customizer.html` - کاستومایزر مهر
- `README.md` - مستندات تغییرات

## نحوه استفاده

### برای کاربران
1. **ایجاد مهر**: از صفحه کاستومایزر استفاده کنید
2. **ایجاد کارت دیجیتال**: فرم کارت دیجیتال را پر کنید
3. **انتخاب کارت فیزیکی**: چک‌باکس مربوطه را انتخاب کنید
4. **فرم AR**: لوگو مهر به صورت خودکار قرار می‌گیرد

### برای مدیران
1. **تنظیمات قیمت**: از منوی "MSP Dashboard > Tarification" استفاده کنید
2. **مشاهده آمار**: از منوی "MSP Dashboard" استفاده کنید

## ویژگی‌های فنی

### JavaScript
- ارتباط بین iframe و صفحه اصلی
- ذخیره لوگو در localStorage
- به‌روزرسانی زنده قیمت‌ها

### PHP
- ذخیره لوگو در user meta
- محاسبه قیمت اپشن‌ها
- ردیابی فعالیت کاربران

### CSS
- طراحی ریسپانسیو
- تم‌های مختلف برای کارت‌ها
- انیمیشن‌های زیبا

## نکات مهم

1. **لوگو مهر**: در فرم AR به صورت خودکار قرار می‌گیرد
2. **قیمت‌گذاری**: از پنل ادمین قابل تنظیم است
3. **آمار**: تمام فعالیت‌های کاربر ردیابی می‌شود
4. **امنیت**: تمام فرم‌ها با nonce محافظت می‌شوند
